# Action Destination Bar — locked geometry

- 8 standard destinations + 1 reserved bonus position.
- 10-column CSS grid.
- Top row: slots 1–4 at columns 2/4/6/8, each spanning 2 columns.
- Bottom row: slots 5–9 at columns 1/3/5/7/9, each spanning 2 columns.
- Slot 9 remains geometrically reserved while hidden.
- Long shallow parallelograms; no subtitles; no movement/scale on hover.
- Standard destinations: Routes, Battle Frontier, Department Store, Game Corner, Graveyard, Ranger Base, Pokémon Center, Bulletin Board.
- Previewing/selecting remains client-local and must reuse the existing V2 Action destination state instead of introducing a second state model.
